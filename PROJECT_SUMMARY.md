## 🚀 Getting Started

### Installation
```bash
cd "Personal Portflio"
npm install
```

### Development
```bash
npm run dev
```

### Production Build

## 🎨 Customization

The website is designed to be easily customizable:

1. **Personal Information**: Update name, title, description in Hero and About sections
2. **Social Links**: Change URLs in Hero, Contact, and Footer components
3. **Skills**: Add/remove technologies in Skills.jsx
4. **Projects**: Update project data in Projects.jsx
5. **Experience**: Modify timeline in Experience.jsx
6. **Colors**: Change theme colors in tailwind.config.js
7. **Contact**: Update email and contact info in Contact.jsx

See **CUSTOMIZATION.md** for detailed instructions.

## 🌐 Deployment
